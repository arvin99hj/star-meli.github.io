REFLECTIONS — CONSTELLATION WEBSITE

PROJECT CONTENTS
- index.html: Website interface
- style.css: Visual design and responsive layout
- script.js: Playback, constellation animation and timing editor
- config.json: Song and project metadata
- lyrics-data.js: Preloaded word timings for the complete supplied lyric sequence
- assets/reflections.mp3: Local audio file

START
1. Extract the ZIP file.
2. Keep the assets folder, config.json and lyrics-data.js beside index.html.
3. Open index.html in a modern browser.
4. Press play. The supplied MP3 is already connected.

CONSTELLATION
The words are preloaded and appear as stars in timestamp order. The active word is displayed while the song plays. The word "eyes" has the special glow enabled.

TIMING EDITOR
1. Open TIMING EDITOR.
2. Play the song and pause at the start of a sung word.
3. Add, remove or edit words and timestamps.
4. Use the highlight checkbox to change the special glow.
5. Changes are saved in this browser automatically.

IMPORT / EXPORT
Use EXPORT TIMINGS JSON to back up edited timings. Import a previously exported JSON file from the editor. The original preloaded timings remain in lyrics-data.js.

IMPORTANT
The supplied word timestamps are estimates. Check them against your exact audio version and adjust them in the editor if necessary.
For best local-file compatibility, keep the MP3 at assets/reflections.mp3. Google Fonts require an internet connection; fallback fonts are available offline.

TAP-SYNC (EXAKTE ZEITSTEMPEL)
1. Klicke TAP-SYNC, druecke Play.
2. Tippe (Leertaste oder grosser Button) genau dann, wenn das hervorgehobene Wort beginnt.
3. Backspace = Rueckgaengig, Pfeil links = 3 s zurueck, Enter = Play/Pause.
4. UEBERNEHMEN wendet die Zeiten auf die Website an, EXPORT JSON speichert sie als Datei.
